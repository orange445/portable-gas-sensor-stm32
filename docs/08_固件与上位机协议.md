# 气体传感固件与上位机协议

## 工程入口

- Keil 工程：`firmware/cubemx/MDK-ARM/GasSensor_STM32G030F6.uvprojx`
- 应用模块：`firmware/cubemx/Core/Src/gas_sensor.c`
- 应用接口：`firmware/cubemx/Core/Inc/gas_sensor.h`
- 上位机：`tools/serial_curve_plotter.html`
- 编译器：Arm Compiler 6.22
- 串口：USART2，115200 bit/s，8-N-1，无流控

上位机仍保留原有 EGFET 功能。打开 HTML 后点击“气体传感工作区”进入本项目页面。气体页面可选择两种连接方式：

- `蓝牙 BLE`：Chrome/Edge 直接连接VG6328A-Pro的GATT透传服务。
- `USB 串口`：115200 bit/s、8-N-1，适合USB-UART调试。

## 固件数据链

TIM3 以 20 Hz 触发 ADC 扫描，DMA 每帧依次保存：

1. `AIN_TIA`
2. `AIN_VCM`
3. `AIN_VFORCE`
4. `BAT_SENSE`
5. `VBUS_SENSE`
6. `VREFINT`

ADC 中断只复制原始码并置位。电压、电流、阻值、安全判断和 UART 发送均在主循环完成。

计算式：

```text
Vsensor = VCM - VFORCE
Vdiff   = VTIA - VCM - Vzero
Isensor = Vdiff / Rf
Rsensor = Vsensor / Isensor
```

默认 `Rf = 12000 Ω`，`Vzero = 0 µV`。固件用 VREFINT 修正 VDDA，并在每个数据帧中同时发送工程量和 6 路 ADC 原始码。主要信号范围仍为0.2–1.6 µA，20 µA以上标记超出推荐区间，持续超过25 µA进入安全关断。

## 安全状态机

| 状态 | 含义 |
|---|---|
| `OFF` | 模拟电源关闭，ADC 仍监测电源 |
| `WARMUP` | `ANA_EN=1`，等待模拟前端稳定 |
| `RUNNING` | 正常输出数据 |
| `LOW_BAT` | 电池不满足启动或运行阈值，模拟电源关闭 |
| `FAULT` | 连续 ADC 饱和、严重偏置异常或持续过流，模拟电源关闭 |

上电默认 `ANA_EN=0`。收到 `GAS,START`、已有有效 ADC 帧且电池不低于3.25 V时，固件立即打开`ANA_EN`并进入150 ms `WARMUP`；运行中电池低于3.10 V会进入安全关闭。

固件0.2.1默认输出率为10 Hz，主机可在1–20 Hz范围内设置输出率；底层ADC固定20 Hz采集。

## 主机命令

每条命令以 `CRLF` 结束。

```text
GAS,HELLO
GAS,STATUS
GAS,RATE,10
GAS,CAL,0,12000
GAS,START
GAS,STOP
```

- `RATE`：输出速率1–20 Hz，默认10 Hz。底层采集始终为20 Hz。
- `CAL`：`GAS,CAL,zero_uV,rf_ohm`，本版只保存在 RAM，复位后恢复默认值。
- `STOP`：立即关闭 `ANA_EN`。

## 设备输出

设备信息：

```text
GAS,INFO,proto=1,fw=0.2.1,acq_hz=20,out_hz=10,rf_ohm=12000,zero_uV=0,cal=ram,reset=POWER_BOR,uptime_ms=12345,ble_log=1
```

状态：

```text
GAS,STATE,RUNNING,WARMUP_DONE
GAS,S,RUNNING,3820,0,10,12000,0,0x0000,0,1
```

`reset`记录最近一次复位来源，常见值为`POWER_BOR`、`NRST`、`SOFTWARE`、`IWDG`和`WWDG`；`uptime_ms`用于判断断链期间STM32是否重新启动。状态帧最后一个字段及INFO中的`ble_log`是已经过滤的蓝牙模块主动日志数。

VG6328A-Pro会在UART上主动输出`+POWERON`、`+CONNECT`、`+MTU`和`+DISCONNECT`等状态行。固件0.2.1起在UART接收边界过滤这些行，避免把它们误判为气体传感命令。

数据帧：

```text
GAS,D,seq,t_ms,I_nA,R_ohm,Vs_uV,VTIA_uV,VCM_uV,VFORCE_uV,BAT_mV,VBUS_mV,flags,raw_tia,raw_vcm,raw_vforce,raw_bat,raw_vbus,raw_vref
```

确认与错误：

```text
GAS,ACK,START
GAS,ERR,BAT_TOO_LOW
```

## 质量标志

| 位 | 十六进制 | 含义 |
|---:|---:|---|
| 0 | `0x0001` | ADC 饱和 |
| 1 | `0x0002` | VCM、VFORCE 或传感器偏置超出推荐区间 |
| 2 | `0x0004` | 电流超出目标测量区间 |
| 3 | `0x0008` | 电流过小，疑似开路 |
| 4 | `0x0010` | 电池低 |
| 5 | `0x0020` | 检测到 USB VBUS |
| 6 | `0x0040` | 充电状态有效 |
| 7 | `0x0080` | 模拟前端预热中 |
| 8 | `0x0100` | VREFINT 结果无效，暂用上次有效 VDDA |
| 9 | `0x0200` | 主循环未及时处理上一 ADC 帧 |

## 标定顺序

1. 断开传感器或建立确定的零电流条件，记录 `VTIA - VCM` 的平均值，作为 `zero_uV`。
2. 测量实际安装的 TIA 反馈电阻，作为 `rf_ohm`。
3. 接入传感器，在已知气体环境中记录稳定的基线电流。
4. 用多个已知浓度点拟合 `ppm = offset + slope × (ΔI/I0)`。
5. 将浓度斜率和截距填入上位机。未完成标准气体标定前，上位机只可信地报告电流、阻值和归一化响应，不应把换算值当成真实 ppm。

显示平滑仅作用于曲线画面；CSV 始终导出原始工程量和 ADC 原始码。

## 浏览器连接

### Web Bluetooth（正式无线使用）

气体页面默认使用Web Bluetooth：

```text
Service FFE0
FFE1 Write Without Response：浏览器 -> BLE -> STM32
FFE2 Notify：STM32 -> BLE -> 浏览器
```

点击“连接蓝牙”，在浏览器设备列表中选择当前模块（出厂广播名可能显示为`VG7439-...`）。连接完成后上位机先开启FFE2通知，再发送`GAS,HELLO`；固件0.2.1依次返回`INFO`和`STATUS`，其中任意一帧都可完成上位机握手。启动时按RATE、CAL、START顺序发送命令。BLE通知可能把一条长数据帧拆成多个20字节左右的数据包；上位机会缓存到`CRLF`后再解析，不把分包当成独立测量点。

GATT连接不等于STM32握手完成。连续3次HELLO没有收到任何FFE2通知时，上位机会显示“BLE已连接/STM32未响应”，并保持“开始采集”禁用；不会再在0 Notify条件下发送RATE、CAL或START。自动重连倒计时或连接请求进行期间也会锁定手动连接按钮，避免两个GATT连接流程竞争。

Web Bluetooth需要Windows版Chrome或Edge，并由用户在连接对话框中选择设备。若浏览器提示安全上下文错误，应通过HTTPS或localhost打开本页面。iOS Safari不作为当前PC上位机的运行环境。

正式使用时可双击`tools/启动气体传感上位机.cmd`。脚本使用已安装的Node.js在`127.0.0.1:8765`启动只读本地服务，并自动打开上位机页面；运行期间保留命令窗口，结束后按`Ctrl+C`关闭服务。

无线链路意外断开不代表STM32已经停止采集或关闭`ANA_EN`。上位机按2.5/5/10/20 s退避重连；重连成功后只发送`GAS,HELLO`和`GAS,STATUS`，不会自动恢复采集。30 s内连续短时断开4次后停止自动重连，避免供电故障造成无限重启。用户主动点击“断开”时，上位机会先尝试发送`GAS,STOP`再断开GATT。

上位机利用`reset`和`uptime_ms`识别PCB是否在断链期间重新启动。若收到`POWER_BOR`且运行时间不足15 s，“开始采集”会暂时锁定到稳定窗口结束。该保护只影响按钮开放时间，不修改固件输出率，也不能替代硬件供电修复。

### Web Serial（调试保留）

选择“USB 串口”后，浏览器必须能看到一个操作系统串口，例如USB-UART调试器。PCB上的USB-C仅充电，不提供USB数据，因此不能直接作为Web Serial端口。
