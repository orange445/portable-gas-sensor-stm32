# 便携式气体传感器测量板

本项目使用小型锂电池供电，在阻性气体传感器两端持续施加约 2.000 V，主要测量图示约 0.2–1.6 µA 的单向电流，并为瞬态和样品差异预留约 10 倍电流余量，通过蓝牙把电流、阻值、偏置和电池状态发送到手机或上位机。

## 当前冻结方案

- 传感器：无源阻性器件，默认不含加热器
- 传感器偏置：`VCM - VFORCE ≈ 2.0016 V`
- 主要测量范围：约 0.2–1.6 µA；宽量程告警上限 20 µA，25 µA持续过流关断
- 主要范围对应电阻：约 10 MΩ–1.25 MΩ；25 µA保护点约80 kΩ
- 电流前端：OPA391 宽量程 TIA，`Rf = 12 kΩ`，`Cf = 47 nF`
- 主控：STM32G030F6P6TR，TSSOP-20
- 采集：STM32 12 位 ADC 单端扫描，固件执行差分相减和过采样
- 蓝牙：VG6328A-Pro 串口透传模块，STM32 与模块用 UART 连接
- 供电：单节保护型 LiPo + USB-C/TP4054 充电 + 3.0 V LDO
- 产品方向：低成本、小面积、可调试、适合连续气体/呼吸响应曲线采集
